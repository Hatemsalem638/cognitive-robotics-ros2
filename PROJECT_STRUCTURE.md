## Executive Summary

This is a **NTU COMP30271 Cognitive Robotics Coursework** project implementing a differential drive robot that:
- **Navigates** using wall-following and SLAM (Person A's task)
- **Detects traffic signs** via YOLOv8 vision (Person B's task)
- **Responds** to signs with velocity commands
- Operates in both **Gazebo simulation** and on real hardware

### Key Workflow
1. Gazebo simulates robot with camera + LiDAR
2. YOLO detects traffic signs → publishes `/yolo/detections`
3. Sign controller responds with `/cmd_vel` commands
4. Wall-follower navigates while responding to signs

## Build & Execution Workflow

### Clean Build
```bash
cd /d:/Cognitive_Coursework
rm -rf build/ install/ log/
colcon build --packages-select yolo_msgs yolo_ros wall_follower simple_robot_description
source install/setup.bash
```

### Run Simulation + YOLO
```bash
# Terminal 1: Gazebo + Mapping
ros2 launch wall_follower official_mapping.launch.py

# Terminal 2: YOLO Detection
ros2 launch yolo_ros yolo_launch.py

# Terminal 3: RViz (optional)
ros2 launch wall_follower official_nav2_sim.launch.py
```

### Topic Flow
```
Gazebo Camera → /camera/image_raw
                    ↓
            yolo_node (YOLO inference)
                    ↓
            /yolo/detections, /yolo/dbg_image
                    ↓
            sign_controller
                    ↓
            /detection_cmd → "STOP", "SLOW", "FAST", "CLEAR"
                    ↓
        sign_response_node (modulates /cmd_vel)
                    ↓
            Gazebo robot moves
```
